# 原子结构 3D 示意模型 HTML

面向人教版高中化学必修一第四章第一节《原子结构》的纯前端离线交互教学页面。适用于教师投屏讲解与学生个人设备探究，覆盖"宏微符三重表征、证据推理、模型认知"三条主线。

[![在线预览](https://img.shields.io/badge/在线预览-GitHub%20Pages-2f6fd0)](https://xmmmymm.github.io/atom-structure-3d/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 快速开始

1. **双击打开 `index.html`**（推荐 Edge 或 Chrome）。断网状态下功能完整可用，无需安装任何依赖、无需构建。
2. 3D 引擎 Three.js r128 已随仓库提供（`vendor/three.min.js`），克隆或下载本仓库后即可直接使用。
3. 若 `vendor/three.min.js` 缺失，页面会显示明确的降级提示层；此时 2D 结构示意图、数值面板、排布探究、数据表、思考与讨论等仍可正常使用。重新获取该文件的方式见 `vendor/README.md`。

> 想先看一眼效果：直接访问 [在线预览](https://xmmmymm.github.io/atom-structure-3d/)（GitHub Pages，内容与本地完全一致）。

## 文件结构

```
/index.html               页面骨架（三页签、模态层、降级层挂载点）
/css/style.css            样式（清爽蓝白教学风、大按钮大字号、响应式）
/js/config.js             全部配置：颜色、半径、粒子数、速度、开关默认值、R1~R7 文案
/js/data.js               数据：1~20 号元素、稀有气体表、五个模型、预设、讨论题、帮助内容
/js/app.js                主程序：场景管理 / 自实现相机控制 / 排布算法 / 2D 绘制 / 导出 / 降级检测
/vendor/three.min.js      Three.js r128（UMD 构建，MIT，已随仓库提供）
/vendor/LICENSE-three.md  Three.js 授权与署名说明
```

> `需求文档.md`（需求与科学口径设计文档）为本地设计依据，未随仓库发布。

## 功能概览

- **页签① 原子构成与质量数**：3D 原子（可点击原子核推近放大，观察质子"红＋"/中子"灰"）、Z/N/A 数值面板、A = Z + N 实时代入算式、真实比例说明弹层。
- **页签② 核外电子排布**：
  - 表征切换：玻尔轨道示意 ↔ 电子云（常驻"教学示意，非真实轨道"等标注）；
  - 排布模式：自动排布 / 手动探究（违规添加被拒绝并指出①~④条款，支持一键纠正、清空）；
  - 离子探究：核外电子数可在 Z±3 内调节（如 Na→Na⁺、Cl→Cl⁻）；
  - 对比模式：左右双 3D 视图独立选元素，预设 Na vs Na⁺、Cl vs Cl⁻、Ne vs Na⁺；
  - 2D 结构示意图（Canvas 实时自绘，含元素符号与电荷，可导出 PNG）、层图例；
  - 思考与讨论（稀有气体表＋三问＋提示/结论）、1~20 号排布数据表（默认隐藏）。
- **页签③ 模型的演变**：五种模型 3D 一键切换（道尔顿实心球、汤姆孙枣糕、卢瑟福核式、玻尔分层轨道、电子云），时间轴＋年代＋科学家＋核心观点，模型评价开关（默认收起），α 粒子散射 2D 示意动画（可展开）。
- **通用**：动画播放/暂停、0.5/1/2 倍速、减少动画模式（静态＋降粒子）、拖拽旋转/滚轮缩放/视图重置、3D 截图与 2D 示意图双 PNG 导出、帮助页（学生版/教师版）、重置回默认（默认＝Na 原子＋轨道示意＋自动排布）、帧率过低时提示开启减少动画。

## 科学性口径与近似性说明

1. **排布算法**：按"每层 ≤2n²、最外层 ≤8（K 为最外层 ≤2）、次外层 ≤18、先内后外"统一实现，1~20 号元素结果全部正确（含 K 为 2,8,8,1；Ca 为 2,8,8,2；Ar 为 2,8,8）。
2. **2,8,8,1 的解释口径**：统一表述为"若第 19 个电子排入 M 层，则 M 层成为最外层且有 9 个，超过最外层≤8，故先排入 N 层"。全站不出现"M 层最多 8 个"的说法。
3. **比例**：所有 3D/2D 图形均为示意比例（核被放大、层间距被压缩）。真实数量级：核直径约 10⁻¹⁵~10⁻¹⁴ m，原子直径约 10⁻¹⁰ m，相差约 10⁵ 倍（页面内有专门说明弹层）。
4. **同位素**：各元素默认取自然界最常见的同位素（Cl 的 defaultA=35，中子数 18；相对原子质量 35.5 为各同位素的加权平均，高中常用近似值）；手动改中子数会标注"同位素"。
5. **表征边界**：轨道动画为玻尔式教学示意，常驻"教学示意，非真实轨道"标注；电子云点云只示意概率分布（点越密概率越大，点不是电子本身），不具定量意义；α 散射为 2D 统计示意动画（大多数直穿、少数偏转、极少数弹回），非真实轨迹与比例。
6. **离子边界**：电子数探索范围限定在 max(1, Z−3) ~ min(20, Z+3)，供课堂探究使用，不代表真实存在的所有离子。

## 自定义

- 改颜色/半径/粒子数/速度/默认开关：编辑 `js/config.js`；
- 改元素数据、模型文案、讨论题、帮助内容：编辑 `js/data.js`；
- 扩展到 21~36 号元素前，请先澄清排布口径的科学边界（现有算法仅保证 1~20 号正确）。

## 兼容性

- 桌面：Edge / Chrome（推荐，WebGL＋Pointer Events）；
- 移动端：简单可用（触屏拖拽旋转、双指缩放，控制面板收进底部按钮）；
- 低配设备：帧率过低时页面会提示开启"减少动画模式"（静态＋电子云 800 点）。

## 部署到你自己的 Pages（可选）

本仓库为纯静态站点，任意静态托管均可直接使用（仓库根目录即站点根目录）：

```bash
# 方式一：GitHub Pages —— 仓库 Settings → Pages → Source 选 main 分支 / (root)
# 方式二：任意静态服务器
python -m http.server 8000     # 然后访问 http://localhost:8000
```

> 说明：直接双击 `index.html`（`file://` 协议）同样可用，因为所有资源均为相对路径且引擎为 UMD 版本，不依赖 ES Module 与网络请求。
